# 30 天路线

## 时间分配

| 阶段 | 天数 | 核心产出 |
|---|---:|---|
| 全栈基础 | 1–5 | React、FastAPI、PostgreSQL 与流式通信贯通 |
| Agent/Harness | 6–18 | Mini Harness、Context、Memory、权限、任务与评测 |
| 交易工具 | 19–21 | Binance、指标、扫描、回测、消息与风险工具 |
| 产品集成 | 22–27 | 可信回答、提醒、RAG、模拟执行、部署 |
| 模型与作品 | 28–30 | LoRA 实验、全面测试、作品集 |

## 学习原则

1. 核心 Agent 代码先手写最小版本，再阅读 DeepSeek Harness 对应源码。
2. 每个行为先写测试并确认测试失败，再实现最少代码使其通过。
3. AI 可以生成重复适配代码，但进入项目前必须能解释、测试并核对数据来源。
4. 价格、K 线与持仓来自结构化工具；RAG 只处理文本资料。
5. 首月禁止自主真实交易和任何提现、转账能力。
